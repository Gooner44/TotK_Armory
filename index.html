Combined totals for every unchecked upgrade tier below, overlapping items added together. Each piece of a set upgrades separately, so a 3‑piece set at Tier 1 costs the listed amount ×3 until all three are checked off.

Location and material data compiled from public Tears of the Kingdom guides (TheGamer, Attack of the Fanboy, Sportskeeda, Zelda Universe, DualShockers) as a stand‑in for mapgenie.io, which couldn't be reached directly. Set portraits and individual‑piece icons are hosted on gamertw.com. Great Fairy Rupee cost per upgrade is flat regardless of set: 10 / 50 / 200 / 500 Rupees per piece, per tier. The save‑file reader is built on the TOTK format reverse‑engineered by marcrobledo/savegame-editors (MIT), item names compiled by Echocolat, Exincracci, HylianLZ and Karlos007. Double‑check quantities in‑game — TOTK's own systems occasionally change with game updates.
